# App and operating system versions

## App versions

Most users have automatic updates turned on and do not notice app updates.

Some users complain about being forced to update to a recent version of the NHS App.

We occasionally set a new minimum version of the NHS App, forcing users to upgrade to that version.

## Operating system and browser versions

We want the NHS App to be available to as many people as possible.
We need the NHS App to remain secure.
We want to minimise the amount of work required to support different operating system versions.

We have to strike a balance between these positions when it comes to deciding how far back we go with testing and supporting operating systems.

We review our [operating system and browser version policy](https://www.nhs.uk/nhs-app/setting-up/supported-operating-systems-and-browsers/) once a year.
