# How should this playbook be organised?

![status: draft](https://img.shields.io/badge/status-draft-orange)

I appreciate that this is a bit meta, but even though this playbook has an obvious organisational structure, it is not entirely clear if this is the correct approach. Right now, we organise by document type, but perhaps we should be organising these materials by value stream instead? 

Further, there is the potential for the [guides](../guides) section to become overly large and unwieldy, so we may need to revisit that approach later.
